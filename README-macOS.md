# 休比桌宠 1.0.3 · macOS 使用说明

## 安装与启动

Apple 芯片 Mac 选择 `arm64` 包，Intel Mac 选择 `x86_64` 包。需要 macOS 14.4 或更新版本。

打开 DMG，将 `SchwiPet.app` 拖到 `Applications`，再从“应用程序”打开。也可解压 ZIP 后移动应用。无需安装 Python、登录或联网。

应用没有 Apple Developer ID 签名或公证，首次打开可能被系统拦截。如果信任本软件，可按 [Apple 的操作说明](https://support.apple.com/zh-cn/guide/mac-help/mh40616/mac)，在系统设置中为这个应用选择“仍要打开”。

## 互动与菜单

- 单击：随机播放害羞、开心、惊讶、挥手、跳跃、期待、兴奋、打瞌睡或猜拳，每轮九种，相邻两次不重复。
- 双击：跳一下。
- 按住拖动：移动休比，转向跟随鼠标移动方向。
- 右键或触控板双指点按：指定动作、调整大小、暂停、开关置顶、视线跟随或小范围散步。
- 顶部菜单栏的休比图标：显示、收起、找回或退出休比。

默认开启置顶和“偶尔自己做动作”，关闭视线跟随和散步。开启散步时，需要同时开启“偶尔自己做动作”。程序不会设置开机启动，不含聊天或语音功能。

## 动作间隔

待机动作默认 10 秒，散步默认 24 秒。右键菜单可选择：

| 设置 | 预设间隔 |
| --- | --- |
| 待机动作间隔 | 5、10、20、30、60 秒 |
| 散步间隔 | 12、24、45、60、120 秒 |

默认值均为第二档；选择“自定义…”可输入 2–300 秒。设置会自动保存。

两种自动动作独立计时，同时到点时依次播放。正在互动、拖动或操作菜单时，自动动作会稍后执行。视线跟随可以与待机动作同时开启，动作结束后恢复跟随。

## 找回、退出与卸载

从菜单选择“找回休比 / 重置位置”可找回角色；选择“退出桌宠”可关闭程序。卸载时先退出，再将应用移到废纸篓，个人设置会保留。

设置保存在 `~/Library/Application Support/SchwiDesktopPet/settings.json`。退出后删除此文件可恢复默认设置；同目录的 `app.log` 可用于排查运行问题。

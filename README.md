# 休比桌宠 1.0.3 使用说明

## 安装与启动

Windows 64 位系统推荐使用 MSI：双击安装包，按向导完成安装，再从桌面或开始菜单打开“休比桌宠”。可在 Windows“设置 → 应用 → 已安装的应用”中卸载，个人设置会保留。

也可使用免安装 ZIP：完整解压后双击 `SchwiPet.exe`，请保留旁边的 `_internal` 文件夹。无需安装 Python、登录或联网。Mac 用户请阅读 [macOS 使用说明](README-macOS.md)。

## 互动与菜单

- 单击：随机播放害羞、开心、惊讶、挥手、跳跃、期待、兴奋或打瞌睡，每轮八种，相邻两次不重复。
- 双击：跳一下。
- 按住左键拖动：移动休比，转向跟随鼠标移动方向，松开后恢复站姿。
- 右键：指定动作、调整大小、暂停、开关置顶、视线跟随或小范围散步。
- 托盘图标：单击显示休比；右键可收起、找回或退出。
- 再次启动：显示已经运行的休比，不会出现多个角色。

默认开启置顶和“偶尔自己做动作”，关闭视线跟随和散步。开启散步时，需要同时开启“偶尔自己做动作”。程序不会设置开机启动，不含聊天或语音功能。

## 动作间隔

待机动作默认 10 秒，散步默认 24 秒。右键菜单可选择：

| 设置 | 预设间隔 |
| --- | --- |
| 待机动作间隔 | 5、10、20、30、60 秒 |
| 散步间隔 | 12、24、45、60、120 秒 |

默认值均为第二档；选择“自定义…”可输入 2–300 秒。设置会自动保存。

两种自动动作独立计时，同时到点时依次播放。正在互动、拖动或操作菜单时，自动动作会稍后执行。视线跟随可以与待机动作同时开启，动作结束后恢复跟随。

## 找回、退出与设置

休比不在可见位置时，从托盘菜单选择“找回休比 / 重置位置”。退出时，在右键或托盘菜单选择“退出桌宠”。

位置和偏好保存在 `%LOCALAPPDATA%\SchwiDesktopPet\settings.json`。退出后删除此文件可恢复默认设置；同目录的 `app.log` 可用于排查运行问题。
